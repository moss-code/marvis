- handler 行为扩展：接受 `.xlsx/.xls/.csv/.txt`

## 2. 解析层规范

### 2.1 `src/main/db/tabular.ts`

```ts
export function importTabular(filePath: string): TableSchema[]
```

| 扩展名 | 处理 |
|---|---|
| `.xlsx` / `.xls` | SheetJS 读工作簿，每 sheet 一表 |
| `.csv` | 编码嗅探 → `XLSX.read(text, { type: 'string', FS: ',' })` |
| `.txt` | 编码嗅探 → 分隔符嗅探 → `XLSX.read(text, { type: 'string', FS })` |
| 其他 | throw 不支持类型 |

### 2.2 编码嗅探（csv/txt）

UTF-8 BOM → UTF-16 LE/BE → UTF-8 fatal → gb18030 兜底

### 2.3 分隔符嗅探（仅 txt）

候选 `\t` `,` `;` `|`；方差最低且中位列数 ≥ 2；失败则拒绝

### 2.4 表名

- xlsx：`data_${sanitize(sheetName)}`
- csv/txt：`data_${sanitize(文件名 stem)}`

## 3. 数据马 Prompt 通用化

`isTelecomDemo(tables)` 检测表名含「营业厅 / 投诉 / 用户增长」→ 注入电信段；否则注入通用段。

## 5. 失败语义

| 错误 | 触发 |
|---|---|
| 不支持的文件类型… | 未知扩展名 |
| 文件过大（>50MB）… | 超限 |
| 文件为空或缺少数据行 | aoa < 2 |
| 文件编码无法识别… | 编码失败 |
| 该 txt 文件不像表格数据… | 分隔符嗅探失败 |
