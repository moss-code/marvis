# Skill Template

Copy this folder to your Pony Office workspace:

```
文档/PonyOffice工作区/skills/<your-skill-id>/
```

Rename the directory to match your skill id (lowercase letters, numbers, hyphens). Update `SKILL.md` frontmatter `name` and `description`.

See [docs/skill-format.md](../../docs/skill-format.md) for the full specification.
